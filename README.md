# 🐾 PetVille

> **Pet Shop & Spa — cuidado, bem-estar e carinho para quem faz parte da família.**

O **PetVille** é um projeto de website desenvolvido para um pet shop e spa, com uma proposta moderna, elegante e acolhedora. O projeto foi criado para apresentar os serviços da empresa, transmitir confiança e proporcionar uma experiência de navegação simples e agradável.

🔗 **[Acesse o projeto online](https://izzarodrigues.github.io/Petville/)**

---

## ✨ Sobre o projeto

O site apresenta uma landing page completa para uma empresa fictícia de cuidados para animais, reunindo informações sobre serviços, diferenciais, depoimentos e formas de contato.

A identidade visual foi pensada para transmitir **carinho, segurança, profissionalismo e bem-estar**, criando uma experiência direcionada aos tutores de pets.

---

## Objetivos

* Criar uma presença digital profissional para o PetVille;
* Apresentar os principais serviços oferecidos;
* Desenvolver uma interface visualmente agradável e intuitiva;
* Facilitar o contato e agendamento;
* Praticar desenvolvimento **Front-End** e criação de interfaces responsivas.

---

## 🐶 Principais seções

### Início

Apresentação da proposta do PetVille, com chamada para ação e destaque para os principais diferenciais.

### Serviços

Apresentação dos serviços disponíveis:

* Banho & Hidratação
* Tosa Artística
* Veterinário
* Pet Shop
* Hotel & Creche
* Spa & Bem-estar

### 🐾 Sobre Nós

Seção institucional destacando a experiência, profissionais, segurança e atendimento personalizado.

### Depoimentos

Área destinada às avaliações e experiências dos clientes. (Atualmente fictícia)

### Contato

Seção final com chamada para agendamento, telefone, endereço e horário de atendimento.

## Tecnologias

* **HTML5** — estrutura semântica da página
* **CSS3** — estilização, layout e responsividade
* **JavaScript** — interações e comportamento da interface
* **Google Fonts** — tipografia
* **Lucide Icons** — ícones da interface
* **GitHub Pages** — hospedagem e publicação

---

## Design

O projeto utiliza uma abordagem visual **minimalista, moderna e acolhedora**, combinando elementos de interface limpa com imagens relacionadas ao universo pet.

A estrutura foi desenvolvida pensando em:

* Hierarquia visual;
* Legibilidade;
* Espaçamento e organização;
* Experiência do usuário;
* Responsividade;
* Chamadas para ação bem posicionadas.

---

## Responsividade

O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência consistente em:

* 🖥️ Desktop
* 💻 Notebook
* 📱 Smartphone
* 📲 Tablet
